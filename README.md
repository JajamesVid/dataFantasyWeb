# dataFantasyWeb
Repository created for the Web Page of DataFantasy project, este es u proyecto para dar informacion analizada en base a los datos estadisticos de los jugadores de futbol de la liga santander. Publicaremos articulos cada semana para analizar cada jornada y ayudar a los jugadores a ganar en sus ligas. Una cosa que podria ser interesante es tener tambien una seccion que analiza el precio de cada jugador, existen ahora mismo plataformas que te dejan comprar jugadores como si fuesen acciones

La pagina web tiene que tener varias secciones:

Home
    Tablon de anuncios
Equipos de la liga
    Una seccion para cada equipo con
        Ultimos anuncios relativos al equipo
        Racha del equipo
        Jugadores más en forma
        Jugadores en caida libre

Buscador de jugadores
    Seccion para buscar un jugador en especifico y que puedas ver
         su historico
         posicion en la que juega
         en que posicion le gusta mas jugar
         con quien juega mejor 
         valor de mercado (fantasy, transfermarkt)
Seccion de comparacion entre 2 jugadores
Seccion de incluir tu equipo y que la pagina web te analice como lo ve, puntos flacos etc
